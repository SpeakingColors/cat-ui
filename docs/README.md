# Mockups

Interactive HTML mockups of cat-ui. Open any file in a browser, keep `support.js` next to it. Knobs, faders and buttons respond, but nothing makes sound or talks to hardware yet. Fonts load from Google Fonts when online.

- [Settings](mockups/Settings.dc.html)
- [SettingsMIDI](mockups/SettingsMIDI.dc.html)

- [Design lessons](DESIGN-LESSONS.md): rules learned from real tests (level matching, repaint, labels, spectrum range). Add new fixes there.
