# Design lessons for every Studio 87 plugin

Rules learned in real testing. Keep adding to this list whenever a bug is fixed. The same list is in the vst-maker-cat skill and in the project notes.

- Drive and saturation stages must not lose level. A static per-stage match (RMS of a 0.3 amplitude sine) is not enough: in the lab, bass-heavy material (rumble kick and bass) was 1.5 to 2.3 dB quieter at 100 % on every drive knob, kick, lead and mix were fine. Fix, same as Cat Spacer's closed-loop RMS gain staging (claude/cat-fx-studio-round2.md): around the whole drive section measure mean-square in and out with a slow one-pole (about 250 ms), makeup = sqrt(in/out) clamped 0.5 to 2.5, glide about 100 ms, exactly 1.0 and bit-exact when all drive knobs are 0. Keep the static match as a starting point. Time constants from 60 ms to 500 ms changed the result by less than 0.1 dB. Test with bass-heavy, drums, lead and mix sources, each knob at 25, 50, 75 and 100 %, compare output RMS to the INPUT RMS (tolerance 0.5 dB), no NaN. The JS lab and the C++ must use the same loop. Earlier static matches: Fat Cat purrMakeup, Scaredy ScaredyCore.h mkS/mkSm.
- Two views of one parameter (small crossover graph and big band spectrum) must both repaint when the value changes from anywhere (other view, host automation, preset). Do not rely on the view's own mouse events. Bug: the small graph only repainted on its own mouse events, so dragging in the big view moved the sound but not the small graph. Fix: repaint it on the editor's frame tick (or a ParameterAttachment callback). Both views share one drag helper (XoverDrag) and one parameter.
- Write the values down. Under the small crossover graph show two value chips ("Low | Mid 160 Hz", "Mid | High 2.8 kHz", teal value on a dark rounded chip). In the big spectrum draw the Hz at the bottom of each crossover line on a dark label, white 1.6 px lines. Plain centred bold text under the graph was rejected by the user.
- Draw-state leak: a helper that draws the arrow glyphs set the stroke colour to a dark outline, so the second crossover line was drawn dark. Set the colour and width inside every loop pass, never once before the loop.
- Envelope lane waveforms show two colours: the untouched band signal and the signal after the ducking, so the user can read how much ducked. Pink = what the ducking removed (pre minus post), band colour = after. Fold per band (pre and post band peaks) by the curve position, not one grey waveform of the whole input. Engine arrays: wavePre[3][256], wavePost[3][256].
- Band spectrum: dB range 0 to -100 (it was -120 to -30 and clipped the original at the top), fill under the original trace in the band colour at low alpha so the whole spectrum looks full, removed part in the strong band colour, dashed original on top.
- Scaredy Cat crossover defaults are 160 Hz and 2.8 kHz (the reference plugin's defaults, the user's choice on 2026-10-19). Replaces 122.2659 and 1976.9132 in item 18. Old saved states keep their own crossover values.
- Releases: the plugin version comes from the release tag (workflow edits project VERSION before cmake), so the gear menu, installer and GitHub release match; no manual version bump. Before any push, pull --rebase: other sessions push to the same repos (a Ko-fi link was added to scaredy-cat that way).
